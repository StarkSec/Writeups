# Root-Me Writeups
This repo documents the vulnerabilities encountered while working through Root-Me challenges — how each one works, how it was exploited, and (most importantly) how it should be remediated. Think of these less as "solve guides" and more as vulnerability case studies: root cause, exploitation path, and lessons learned for each one.

Each write-up covers:
- **Vulnerability class** — what the underlying flaw actually is
- **Exploitation** — how it was identified and abused
- **Remediation** — how it should be fixed in a real environment
- **Lessons learned** — the broader takeaway for defense/detection
